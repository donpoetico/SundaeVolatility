# Sundae Volatility

> Educational derivatives pricing game with incremental mechanics and diegetic shop-language.

## Core Architecture
- **Three-Layer Architecture**: Core engine, Game logic, UI.
- **Language**: TypeScript (Strict Mode).
- **State Management**: Zustand (with persistence).
- **UI**: Vanilla DOM + CSS (minimal prototype).
- **Math Engine**: Black-Scholes pricing and Greeks.

## Development Principles
- **Diegetic Metaphor**: Player-facing language uses "promises," "tools," "weather," and "flavors."
- **Mixed-Audience Rule**: Tutorials and docs introduce diegetic terms first, then technical labels in parentheses when needed.
- **Invisible Simulation**: Finance terminology is hidden from the player until explicitly taught.
- **TDD Mandatory**: All logic must be verified by tests.
